🏃 What is Motion?

Lesson 1 • Learn → Practice → Master

🔥 0⭐ 0 XP❤️ 5

🧠 Learn

Motion describes a change in the position of an object with respect to a chosen reference frame as time changes. Whether an object is moving or at rest depends on the reference frame used.

Key idea: Motion is relative to a reference frame.
