🔥 KP Physics Academy — Firebase Setup

This page documents the next app-development step. Your existing lessons continue to work with browser storage; Firebase will become the persistent student account/progress layer.

Step 1 — Firebase project

Create or open the Firebase project connected to KP Physics Academy.

Step 2 — Authentication

Enable Email/Password authentication first. Google sign-in can be added later.

Step 3 — Firestore

Create a Cloud Firestore database. Recommended first document structure:

users/{uid}
  displayName
  email
  xp
  streak
  hearts
  currentCourse
  currentLesson
  kinematicsMastery
  createdAt
  updatedAt
Step 4 — Lesson progress

Use a subcollection for scalable progress:

users/{uid}/lessonProgress/{lessonId}
  completed
  bestScore
  attempts
  xpEarned
  lastAttemptAt
Step 5 — Security

Students should only read and write their own users/{uid} data. Do not put Firebase Admin credentials or server secrets in GitHub Pages JavaScript.

Step 6 — FlutterFlow

Connect the same Firebase project to FlutterFlow. Then create Login → Home → Course Path → Lesson → Result screens. The website can remain the public prototype while the FlutterFlow app becomes the mobile product.

Next coding task: create the Firebase Authentication login/register page and then connect the lesson progress model.
